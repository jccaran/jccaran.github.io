# jccaran.github.io

Personal portfolio site for Chris Caran — built with React + Vite.

## Stack

- React 18 + React Router v6
- Vite 6
- Plain CSS (custom properties, no frameworks)
- Deployed to GitHub Pages

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The built files land in `dist/`. For GitHub Pages deployment, push `dist/` contents to the repo root on the `main` branch, or configure a GitHub Actions workflow to deploy automatically.
